Why it matters: agentic systems fail the moment the model can decide. This pattern makes that structurally impossible — fork it for your domain.

how it works

You declare inputs and the laws that close them. A deterministic gate walks the dependency map and issues a receipt: what computes, what is refused, which laws are missing, and a SHA-256 over the result. No language model has run yet.

Only then is the receipt handed to Nemotron, which restates it in English under a strict schema. Every status it echoes is compared back against the receipt, every number it quotes must trace to one, and any disagreement refuses the whole answer — the receipt still stands, rendered without a model.

One output, defensive_factor, is a lawless output: no closing relation for it exists. It stays refused even when every law is declared. Watch what the attacks below try to do about that.
